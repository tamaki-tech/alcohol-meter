# Handoff: alcohol-meter（Android / ヘルスコネクト連携）画面仕様

> プロダクト名は仮称「alcohol-meter」。アプリ名・通知のアプリ名表示・パッケージ名の一部に使う。

## Overview
alcohol-meter は、飲み会の開始〜お開きまでの飲酒を 1 杯ずつ記録し、推定 BAC・休肝日を表示し、ヘルスコネクトへ書き込む Android アプリ。本書はその画面仕様。最優先の UX 目標は **「飲み会中に手早く・確実に 1 杯を記録できること」**。

機能仕様・データ仕様・BAC 計算式は `reference/original_spec.md`（元の CLAUDE.md）（元の仕様書）が正。本 README は **画面・見た目・操作** を定める。両者が食い違う場合、見た目と操作は本 README、ロジックとデータは original_spec.md を優先する。

## About the Design Files
同梱の `alcohol-meter_v2.dc.html` は **HTML で作ったデザインリファレンス**（見た目と挙動を示すモック）であり、そのまま組み込むコードではない。ブラウザで開くと全画面がキャンバス上に並ぶ（同フォルダの `support.js` と `_ds/` が必要）。
実装は **Kotlin + Jetpack Compose** で、本 README の値を元に再構築すること。Material 3 コンポーネントを使う場合は、色・形状・タイポを下記トークンで上書きする。

## Fidelity
**High-fidelity**。色・タイポ・余白・角丸・状態は最終値。モックは幅 360dp 基準で、1px = 1dp として読む（フォントサイズは sp）。

キャンバス上の **1a / 1c は不採用案**（比較用）。飲み会中画面は **1b「もう 1 杯」優先** を実装する。

## 共通部品

### ボトムナビ
高さ 64、上辺 1dp divider。4 等分：ホーム / 履歴 / カレンダー / 設定。アイコン 22 + ラベル 11、間隔 3。アクティブ = primary、非アクティブ = muted。インジケータの塗りはなし。

### ボタン
- **Primary**: 塗り primary / 文字 onPrimary / 角丸 10（CTA は 14）。押下で primary pressed。
- **Secondary**: 透明 / 枠 1dp divider / 文字 onSurface。押下で pressed tint。
- **Ghost**: 枠なし。押下で pressed tint。
- リップルは使わず、押下時の色変化のみ（`indication = null`＋押下状態で背景を変える）。

### スナックバー（記録の取り消し）
- 位置: 左右 12、ボトムナビの上 12（画面下端から 76）。
- 中身: 左にテキスト 14、右に「取り消し」（16 / 600、下線、高さ 48）。
- 下辺に 3dp の残り時間バー（onSurface 色、5 秒で 100%→0% を線形に減らす）。
- 5 秒で自動的に消える。新しい記録をすると置き換わる（取り消せるのは常に直前の 1 杯）。

**記録時の挙動（全ボタン共通）**
- タップした瞬間に記録する（**確認なし**）。
- 触覚フィードバック: `HapticFeedbackType.LongPress` 相当、または 30ms の振動。

### 9. プリセット編集
- 上部バー 56: 閉じる（×）、「プリセットを編集」20/600、右に「保存」Primary（高さ 44 以上）
- **プレビュー**: 飲み会中のドリンクボタンと同じ部品（幅 160 / 高さ 92）をリアルタイムで表示
- 入力欄（高さ 48、枠＋角丸 10、フォーカス時は枠 primary、ラベル 12）:
  - 名前（テキスト）
  - 量 ml / 度数 %（2 列、数字キーボード、単位は右寄せの muted）
  - 種類（ヘルスコネクトの種類、ドロップダウン）
- 色: 6 色のスウォッチ（44×44 の円、間隔 8）。選択中は外側 2dp オフセットに 2dp の onSurface 輪
- 「通知に出す」スイッチ（48×28、丸型）＋補足「最大 3 件（現在 3 件）」。3 件に達していたら OFF→ON にできないので、理由を表示する。
- 純アルコール量（量 × 度数 / 100 × 0.8）は自動計算

### 10. オンボーディング（4 ステップ）
共通: 上部に 4 分割の進捗バー（高さ 3、角丸 999、間隔 4、済＝primary / 未＝divider）。見出し 32/600、補足 14（70%）。下端に CTA（高さ 56、横幅いっぱい）。
1. **対応チェック**: スプラッシュ中に自動で行う。対応端末なら画面を出さない。非対応なら 11 へ。
2. **体重・性別**: 体重 64/600 ＋「kg」、下線 2dp primary。ヘルスコネクトに最新の体重があれば初期値に入れ、「ヘルスコネクトの最新値（11/12）を入れています」と表示。性別は 2 択（高さ 56）。CTA「次へ」。
3. **ヘルスコネクト**: 権限の説明 2 行（飲酒記録の書き込み / 体重の読み取り）。CTA「ヘルスコネクトで許可」＋Ghost「連携せずに使う」。
   - **拒否されても先に進める**。アプリ内の記録だけで使え、サマリ・履歴・設定に「未連携」と出す。設定からいつでも連携できる。
4. **通知**: 常駐通知の見本カードを見せてから許可を求める。CTA「通知を許可」＋Ghost「あとで」。

### 11. 非対応端末
中央寄せ（下 80 だけ上にずらす）: 警告アイコン（72×72 の枠）→「この端末は非対応です」32/600 → 説明 14 → 区切り線の下に「Android 14〜16：ヘルスコネクトの更新が必要です / Android 17 以降：標準で対応」13 muted。**操作ボタンは置かない**。

### 12. 常駐通知（OS が描く — 見た目は変えられない）
- フォアグラウンドサービスの通知。アプリ名表示は「alcohol-meter」。タイトルは Chronometer（開始時刻からの経過）「飲み会中 1:42:18」、本文「4 杯 ・ 推定 BAC 0.045%（推定値）」。
- アクションはプリセットのうち「通知に出す」3 件。ラベルは **名前のみ**（短い名前）。タップで記録し、本文の杯数を更新する。
- 通知アイコンは beer の単色シルエット。`setColor` は使わない（モノトーン）。
- **お開き忘れ通知**: 最後の 1 杯から一定時間たったら「お開きしますか？」「最後の 1 杯（21:14）から 6 時間たちました」。アクションは「21:14 でお開き」「続ける」。

## Interactions & Behavior（まとめ）
- 誤タップ対策は確認ダイアログではなく **5 秒の取り消し** で行う（記録の操作だけ）。お開き・削除は確認する。
- 破壊的な操作（お開き・削除）は、よく押すボタンから離して置く。
- 押下時の手応えは「色の変化 + 触覚 + 数字の拡大」の 3 つ。リップルは使わない。
- アニメーションは控えめに。シート・ダイアログは 200ms（ease-out）、スナックバーは下から 150ms。
- 画面は edge-to-edge。ステータスバーとナビゲーションバーの余白（インセット）を確保し、ボトムナビはジェスチャーナビの上に置く。

## State Management
- `Session?`（進行中の飲み会）: startAt, logs[ {presetId, at, ml, abv, g} ]
- `uiState.lastUndoable`: 取り消せる直前の 1 杯と、その期限（5 秒）
- `presets`: 並び順, name, shortName, ml, abv, hcType, colorIndex(0–5), showInNotification（最大 3）
- `profile`: weightKg, sex, eliminationRate（0.015 %/時）
- 派生値: cups, totalG, bacNow, soberAt, countsByPreset, lastPreset
- 休肝日の判定は AM 3:00 区切り（original_spec.md に準拠）
- ヘルスコネクトの状態: granted / denied / unsupported と、記録ごとの送信状態（sent / failed / pending）
